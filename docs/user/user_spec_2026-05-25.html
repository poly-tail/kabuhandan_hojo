1. 目的と利用範囲

株判断補助アプリは、日本株について「今どこを見るべきか」を整理するローカル運用前提のアプリです。利用者は保有銘柄、ウォッチリスト、個別銘柄の材料、チャート、需給、AI分析を確認できます。

主な利用場面は、保有銘柄の定期レビュー、ウォッチリストの監視、材料発生時の確認、チャートや需給の確認、決算や開示前後の見直しです。

AI分析は「判断材料・反証条件・リスク」を整理します。「必ず買う」「必ず売る」といった断定や、自動発注は行いません。

利用者ができること

  • 保有銘柄を登録し、数量や平均取得単価を管理する。
  • ウォッチリストに監視銘柄を登録し、気になる銘柄だけ選択してAI分析する。
  • 銘柄ごとの材料、テクニカル、チャート、需給、スコアを確認する。
  • OpenAI APIを使い、保有銘柄または選択したウォッチリストをまとめてレビューする。
  • APIを呼ばないサンプル表示で、画面表示だけを確認する。

2. 主要画面

ダッシュボード 市場概況、優先確認銘柄、アラート、保有銘柄、ウォッチリスト、材料、スクリーニングをまとめて確認する中心画面です。
保有銘柄 保有銘柄の登録、一覧確認、評価額確認、保有銘柄の一括AI分析を行います。
ウォッチリスト 監視中の銘柄を一覧し、選択した銘柄だけAI分析できます。
個別銘柄 仮説メモ、地合い分解、材料、テクニカル、需給、スコア、参照リンクを確認します。
チャート 20日、40日、全期間の切り替え、移動平均、RSI、MACDを確認します。

3. 保有銘柄機能

保有銘柄は、実DBに登録された銘柄を優先して利用します。未登録またはテスト時には、サーバー側の仮保有銘柄を利用できます。

保有銘柄の優先順位

  1. 実DBに登録されている保有銘柄
  2. ローカルストレージや設定ファイルの保有銘柄
  3. テスト用の仮保有銘柄

4. ウォッチリスト機能

ウォッチリストは、まだ保有していない銘柄や追加監視したい銘柄を確認するための機能です。ダッシュボード上でAI分析対象をチェックし、選択した銘柄だけをまとめて分析できます。

主な状態

  • AI分析対象に選択済み
  • 未選択
  • 全選択
  • 選択解除
  • 分析実行中
  • 成功または失敗

5. AI分析機能

AI分析はバックエンドからOpenAI APIを呼び出します。APIキーはフロントエンドに置かず、サーバー環境変数のOPENAI_API_KEYから読み込みます。利用モデルはOPENAI_MODELで指定し、未指定時はアプリ側のデフォルトを使います。

分析対象

  • 保有銘柄を一括AI分析
  • テスト用仮保有銘柄で分析
  • 選択ウォッチリストをAI分析

画面上のボタンと選択肢

保有銘柄を一括AI分析 実DBの保有銘柄を優先し、登録がない場合は条件に応じて仮保有銘柄を分析します。
テスト用仮保有銘柄で分析 実DBの内容に関係なく、サーバー側の確認用銘柄セットで分析します。
選択ウォッチリストをAI分析 ウォッチリストでチェックした銘柄だけを分析します。
最新ニュースも検索（OpenAI API使用） OpenAI APIのWeb検索ツールを使い、公開情報も確認します。通常より時間とAPI利用量が増えます。
APIなしのサンプル表示（課金なし） OpenAI APIを呼ばず、固定のサンプル結果を表示します。画面確認用であり、実分析ではありません。

AIカードの表示項目

  • 銘柄コード、銘柄名
  • 総合判断と日本語ラベル
  • 信頼度 confidence
  • 今日見るべきポイント
  • テクニカル所見
  • 材料・ニュース所見
  • 保有者向けアクション
  • 反証条件
  • リスク
  • 参照元URL

判断ラベル

hold: 保有継続 buy_more_candidate: 買増し候補 take_profit_candidate: 一部利確候補 reduce_risk: リスク低減 watch: 様子見

APIの主な状態

未実行まだ分析を開始していない状態です。
実行中バックエンドでOpenAI APIまたはサンプル分析を処理中です。
成功JSONレスポンスを受け取り、銘柄別カードを表示できる状態です。
失敗APIキー、請求、利用上限、モデル名、通信、JSON解析などで処理できなかった状態です。
APIキー未設定OPENAI_API_KEYがサーバーに設定されていません。
JSON parse失敗モデル応答が指定形式のJSONとして読めなかった状態です。画面には安全なエラー情報だけ表示します。
Web検索なしの簡易分析Web検索を使わず、アプリ側のデータとプロンプトだけで分析します。

6. データと参照元

本アプリの基幹データ源は、J-Quants、EDINET API、YouTube Data API、明示的に許可したIRサイトです。Web検索を使うAI分析では、OpenAI API側の検索結果が参照元として返る場合があります。

データ種別

株価・市場データJ-Quants連携を前提とします。AIレビュー用のマーケットスナップショットは、実データ接続前でも動作確認できるように仮データを返せる構造です。
開示・決算EDINET API、TDnet連携、許可済みIRサイトを対象にします。
動画材料YouTube Data APIで登録済みチャンネルを確認します。
手動参照リンク画面上の参考リンクとして扱います。基幹ソースとして自動取得するものではありません。

7. セキュリティ

  • OpenAI APIキーはバックエンドのみで読み込み、フロントエンドには露出しません。
  • .envはgit管理対象外です。
  • .env.exampleにはキーの値を入れず、設定項目だけを記載します。
  • APIエラー時、画面にはAPIキーや内部スタックトレースを表示しません。
  • ログは必要最低限に抑えます。

8. 制約と残課題

  • OpenAI APIの実行には、OpenAI Platform側の請求設定、利用上限、モデル利用権限が必要です。ChatGPT PlusなどのWeb版契約とは別管理です。
  • Web検索ありのAI分析は、検索なしより時間がかかり、API利用量も増えます。
  • AIの出力は、公式開示、株価、出来高、決算、リスク要因と合わせて確認してください。
  • AIレビュー用のマーケットスナップショットは、実株価APIへの差し替えを前提にしたサービス層に分離されています。
  • 外部サイトの規約違反やrobots無視を前提にした取得は行いません。
