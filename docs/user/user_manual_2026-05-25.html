日々の保有銘柄レビュー、ウォッチリスト確認、AI分析の使い方

作成日2026年5月25日
対象者アプリ利用者、運用確認者
利用画面/ui/dashboard を中心に操作します。
注意本アプリは判断補助です。売買の最終判断は、公式情報と自身の投資方針に基づいて行ってください。
AIの回答は、公式開示、株価、出来高、決算、需給、地合いと合わせて確認してください。アプリは自動売買や投資助言の断定を行いません。

1. 起動と事前準備

ローカル環境でAPIサーバーを起動し、ブラウザでダッシュボードを開きます。

起動コマンド

python scripts/run_api.py --reload

起動後、通常は次のURLを開きます。ポートを変更している場合は、起動ログに表示されたURLに合わせてください。

http://127.0.0.1:8000/ui/dashboard

AI分析に必要な環境変数

OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-5.5
OPENAI_REASONING_EFFORT=high
  • OPENAI_API_KEYはOpenAI PlatformのAPIキーです。ChatGPT Web画面のログイン情報ではありません。
  • OPENAI_MODELは利用するモデル名です。利用権限がないモデル名を指定するとAPIエラーになります。
  • OPENAI_REASONING_EFFORT=highにすると、reasoning対応モデルでは高めの推論設定をバックエンドから送ります。
.envはgit管理対象外です。.env.exampleにはキーを入れず、項目名だけを残します。

2. ダッシュボードの見方

Market Overview 市場全体の状態や、TOPIX/Nikkei225 proxyの確認に使います。
Portfolio 保有銘柄の一覧、登録、保有銘柄AI分析を行います。
Watchlist 監視銘柄の確認、選択銘柄のAI分析を行います。
Materials 開示、IR、動画などの材料を確認します。
Screening 条件に合う銘柄を探すために使います。

3. 保有銘柄をAI分析する

保有銘柄パネルの「保有銘柄を一括AI分析」から、登録済み保有銘柄をまとめてレビューできます。

実分析の手順

  1. ダッシュボードのPortfolio欄で保有銘柄を確認します。
  2. 最新情報も確認したい場合は「最新ニュースも検索（OpenAI API使用）」をONにします。
  3. 実際にOpenAI APIを呼ぶ場合は「APIなしのサンプル表示（課金なし）」をOFFにします。
  4. 「保有銘柄を一括AI分析」をクリックします。
  5. ローディング表示が終わったら、銘柄別カードを確認します。

画面表示だけ確認する手順

  1. 「APIなしのサンプル表示（課金なし）」をONにします。
  2. 「保有銘柄を一括AI分析」をクリックします。
  3. 固定のサンプル結果が表示されることを確認します。

テスト用仮保有銘柄

実DBに保有銘柄がない場合や、テスト用銘柄で確認したい場合は「テスト用仮保有銘柄で分析」を使います。確認用銘柄は以下です。

3563FOOD & LIFE COMPANIES / F&LCホールディングス
7011三菱重工業
6758ソニーグループ
7203トヨタ自動車
7974任天堂
回答が極端に早い場合は、「APIなしのサンプル表示（課金なし）」がONになっている可能性があります。実分析したい場合はOFFにしてください。

4. ウォッチリストをAI分析する

ウォッチリストでは、分析したい銘柄だけを選んでAI分析できます。保有していない候補銘柄の材料整理に使います。

操作手順

  1. Watchlist欄で、分析したい銘柄の「AI分析」チェックをONにします。
  2. まとめて選ぶ場合は「全選択」、外す場合は「選択解除」を使います。
  3. 最新情報も確認したい場合は「最新ニュースも検索（OpenAI API使用）」をONにします。
  4. 実APIを使う場合は「APIなしのサンプル表示（課金なし）」をOFFにします。
  5. 「選択ウォッチリストをAI分析」をクリックします。

選択が0件の場合は分析できません。少なくとも1銘柄を選択してください。

5. AI分析結果の読み方

総合判断 hold、buy_more_candidate、take_profit_candidate、reduce_risk、watchのいずれかです。
判断ラベル 「保有継続」「買増し候補」「一部利確候補」「リスク低減」「様子見」のように日本語で表示されます。
confidence AIがその判断にどの程度自信を持っているかの目安です。低い場合は材料が弱い、データが足りない、地合いが不安定といった可能性があります。
今日見るべきポイント 当日または直近で確認すべき価格帯、出来高、支持線、抵抗線、材料を確認します。
テクニカル所見 移動平均、RSI、MACD、支持線、抵抗線などの観点です。株価データが不足している場合は断定されません。
材料・ニュース所見 Web検索ONの場合は公開情報を踏まえます。確認できない場合は「材料なし」または根拠が弱い旨が表示されます。
保有者向けアクション 保有継続、一部利確、押し目待ち、リスク低減など、保有者目線の次の確認行動です。
反証条件 AIの見立てが崩れる条件です。支持線割れ、出来高不足、決算悪化、材料否定などを確認します。
リスク 地合い悪化、決算前後の急変、為替、金利、需給悪化、過熱感などの注意点です。
参照元URL Web検索で参照元が返った場合にリンク表示されます。重要な判断前には元ページを確認してください。

6. エラー時の確認

APIキー未設定 .envにOPENAI_API_KEYが設定されているか確認し、サーバーを再起動します。
利用上限または請求設定 OpenAI Platformのbilling、usage、quotaを確認します。ChatGPT Web版の契約とは別です。
モデル名エラー OPENAI_MODELに指定したモデルが利用可能か確認します。利用権限がないモデルは実行できません。
JSON parse失敗 モデル応答が指定JSON形式で返らなかった状態です。画面にはraw_model_outputの一部を含む安全なエラーが表示されます。
Web検索ありで遅い 公開情報検索を含むため、検索なしより時間がかかります。急ぎの確認では「最新ニュースも検索（OpenAI API使用）」をOFFにします。
結果がサンプルに見える 「APIなしのサンプル表示（課金なし）」がONになっていないか確認します。ONのままではOpenAI APIを呼びません。

7. 日々の運用例

  1. ダッシュボードを開き、市場概況とアラートを確認します。
  2. 保有銘柄の評価額と材料を確認します。
  3. 保有銘柄を一括AI分析し、反証条件とリスクを確認します。
  4. 気になる銘柄は個別銘柄画面を開き、材料、テクニカル、需給、チャートを確認します。
  5. ウォッチリストから当日確認したい銘柄だけ選び、AI分析します。
  6. 売買判断を行う前に、公式開示、株価、出来高、決算、地合いを必ず確認します。
