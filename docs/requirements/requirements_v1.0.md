# kabuhandan_hojo 要件仕様書 v1.0

## 1. 目的

日本株の監視と判断補助を行うローカルアプリを提供する。ユーザーが地合い、材料、需給、テクニカルを横断して確認できることを目的とする。

## 2. 基本方針

- 自動売買は行わない
- 断定的な投資助言を行わない
- 正式ソースを優先する
- 規約違反のスクレイピングを行わない

## 3. 機能要件

- watchlist の登録、一覧、再利用ができる
- 銘柄検索から個別銘柄ページへ遷移できる
- 個別銘柄で仮説、テクニカル、需給、材料、参考リンクを見られる
- chart detail で価格推移と補助指標を確認できる
- dashboard で priority、alerts、event feed、候補銘柄を見られる

## 4. データ要件

- 価格データは J-Quants を第一候補とする
- 開示データは EDINET API を canonical source とする
- allowlist IR と YouTube Data API は補助ソースとする
- 手入力 API を検証用の正式経路として持つ

## 5. 非機能要件

- ローカルで起動できる
- mock mode と live mode を切り替えられる
- live mode では mock 補完を行わない
- データ欠損時は `未取得` または空表示で扱う
