# 個別銘柄MVPで使う共通入力ルール

- 銘柄名・コード、市場、利用可能な銘柄マスタ情報を、実行時の銘柄contextとして扱う。
- 現在価格・取得時刻、基準となる市場データ日時、保有状況、許容損失、時間軸など、入力されていない項目を入力済みとして扱わない。
- APIの回答preset `STANDARD` と、原資料の分析深度 `quick / standard / deep` は別の軸であり、相互に読み替えない。
- ユーザー自由質問は「特に見てほしい観点」として扱うが、事実の証拠や確認済みデータとして扱わない。
- 不足情報は、取得可能なら補完し、取得不能なら【U】として残すこと。
